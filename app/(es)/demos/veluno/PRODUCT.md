# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Visitors of the NEXA portfolio (potential clients of the studio) who open the demo to judge NEXA's frontend craft. Inside the fiction, the page addresses shoppers of a consumer electronics store.

## Product Purpose
A faithful frontend recreation of a reference hero for "Veluno", an electronics store, built to show visual fidelity and finish. Success: the page reads as a professionally built storefront hero that matches the reference at desktop, tablet and phone sizes.

## Positioning
A recreation, not a real store. Its value is precision: the reference composition, typography and states rebuilt as real, accessible, responsive code.

## Operating Context
Lives at `/demos/veluno` inside the NEXA portfolio (Next.js 16, App Router), next to the other demos. Runs locally with `npm run dev`.

## Capabilities and Constraints
- No backend, no catalog, no cart, no checkout, no search engine. Controls that would need one must not pretend to complete an action.
- Not linked from the portfolio home, case studies or sitemap yet.
- Photography was supplied by the user (stored in public/demos/veluno); the reference photos themselves are not available.

## Brand Commitments
- Name and copy are exactly the reference's: "Veluno", nav "Inicio, Nosotros, Tienda, Novedades, Contacto", "Buscar", "Tecnología inteligente, vida más simple", "Mejora tu día a día con los productos electrónicos de Veluno, diseñados para brindar confort, estilo y rendimiento.", "Comprar ahora", product "SonicWave", "Sonido envolvente con graves profundos, agudos cristalinos y tonos ricos y dinámicos.", "$ 99.99".
- The attached reference image is the visual authority.
- Whether Veluno exists as a real brand is unconfirmed.

## Evidence on Hand
Only the reference image. No testimonials, customers, ratings, stock levels, shipping terms, extra products or prices beyond "$ 99.99": none may be invented.

## Product Principles
1. The reference decides how it looks; code decides how well it works.
2. Nothing fake: every control is honest about what the demo can do.
3. Same composition at every size, reorganized on purpose where it cannot fit.

## Accessibility & Inclusion
WCAG 2.2 AA: contrast, visible focus, keyboard operation, labelled icon controls, reduced motion respected.
